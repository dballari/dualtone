# DualTone

DualTone is a two-column blog theme with a sticky left sidebar, created as a tribute to **b2/cafelog**, the origins of WordPress more than 21 years ago, which also used a two-column layout.

The theme focuses on clarity and content-first design. It includes:
- A content-wide page template suitable for legal or long-form text
- A blank template for building custom layouts
- Several custom block style variations
- Multiple theme styles, including a light default style and a futuristic dark style
- Two block sections with contrast and accent color backgrounds
- A small settings page with pattern-related options

DualTone is designed to be simple, clean, and distraction-free, allowing readers to focus on the content.

The theme works with **WordPress 6.7** and later.

## Project status

**DualTone (original)** is now considered a **stable, legacy version** of the theme.

The theme is no longer actively developed within the WordPress.org theme repository, but it is preserved here for reference, historical purposes, and for users who may still rely on it.

All future development will continue under a new project:

**DualTone 2** — a modern evolution of the original idea, actively maintained and developed independently.

The original DualTone codebase remains available to ensure transparency, continuity, and respect for the open-source ecosystem. If you are starting a new project, you are encouraged to follow the development of **DualTone 2** instead.
